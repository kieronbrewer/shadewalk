About ShadeWalk

Created by Kieron Brewer using Google Antigravity.

Overview

ShadeWalk is a smart pedestrian routing web application designed to help walkers, runners, and dog-walkers find paths that maximize shade from trees and buildings, minimizing direct sun exposure.

How It Works

ShadeWalk calculates real-time pedestrian routes using current solar geometry, street orientation, and weather conditions. It supports two primary modes:

  • Loop Walk: Generates a natural walking circuit of a target distance starting and ending at the same location. It selects pivot nodes in different compass directions (North, East, South, West) and applies weight penalties on return paths to avoid retracing steps.
  • Point-to-Point: Finds the shadiest path between a starting location and a destination.

Core Technology & Algorithms

Solar Geometry Calculations

Rather than relying on external APIs for solar data, ShadeWalk includes a pure JavaScript implementation of NOAA's solar position algorithms. It calculates the sun's exact azimuth (compass angle) and elevation (angle above the horizon) in real-time based on your geographic coordinates, current date, and time.

Dijkstra Heuristic Cost Routing

To calculate paths, the app runs a custom Dijkstra shortest-path algorithm over street network graphs. The cost function dynamically weights edges based on their exposure to the sun:

Edge Cost = Distance × (1 + (1 - Shade Score) × Shade Importance × (1 - Cloud Cover / 100))
  • Shade Score: Computed dynamically per street segment by comparing the street's angle to the sun's azimuth, combined with tree canopy density markers imported from OpenStreetMap.
  • Cloud Cover Integration: Fetches real-time cloud data from the Open-Meteo API. If the sky is overcast (100% cloud cover), the sun penalty scales down to 0, yielding the standard physical shortest route.

High-Availability OpenStreetMap Fetching

Street graphs and canopy data are retrieved on-demand from the OpenStreetMap database. To avoid query failures during public server outages, the app uses a failover system rotating through four public Overpass API mirrors with a 12-second abort timeout per request.

Privacy-Focused Analytics

To track website traffic without displaying intrusive cookie banners or violating user privacy, ShadeWalk is integrated with a self-hosted instance of Plausible Analytics. It is completely cookie-free and tracks absolutely no personally identifiable information (PII).
